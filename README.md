# 🎮 배그 킬내기 실시간 기록판

친구들과 배틀그라운드를 플레이하며 킬 수와 순위 점수를  
실시간으로 함께 기록할 수 있는 웹사이트입니다.

방을 만들고 공유 링크를 보내면, 참가자 모두가 같은 기록판에서  
팀 정보와 점수를 수정할 수 있습니다.

---

## ✨ 주요 기능

- 실시간 킬내기 방 생성
- 방 코드 또는 공유 링크로 참가
- 최대 5개 팀 생성
- 팀별 팀원 추가 및 팀원별 킬 수 기록
- `+ / −` 버튼으로 킬 수와 순위 횟수 간편 수정
- 팀 전체 킬 수 자동 합산
- 팀별 종합점수 및 전체 팀 종합점수 자동 계산
- 여러 참가자의 수정 내용을 실시간으로 반영
- 모바일 및 PC 브라우저 지원

---

## 🏆 점수 규칙

| 항목 | 점수 |
|---|---:|
| 킬 1회 | +1점 |
| 3등 | +6점 |
| 2등 | +8점 |
| 1등 | +10점 |
| 순위권 밖 | −3점 |

### 종합점수 계산식

```text
종합점수 =
전체 킬 수
+ (3등 횟수 × 6)
+ (2등 횟수 × 8)
+ (1등 횟수 × 10)
− (순위권 밖 횟수 × 3)
